# LINEスタンプ効果設計ガイド

## 公式情報から抽出した条件

### 1. 日常の返事・挨拶を核にする

「了解」「OK」「ありがとう」「よろしくお願いします」「おはよう」「おつかれさま」「おやすみ」「ごめんなさい」など、使用頻度の高い返事・挨拶は基本パックとして優先する。同じセットに了承表現が複数あってもよい。

### 2. ポジティブ表現を中心にする

いいね、同意、楽しい、嬉しい、笑い、ハート、キラキラなど、送信者の感情補足にも使える表現を中心にする。否定・苛立ち・拒否などは、誤解や相手を傷つける可能性があり使用頻度が下がりやすいため、少数または明確なコンセプト内に限定する。

### 3. 限定的な行動だけの絵を増やしすぎない

特定の趣味・行動・場面にしか使えない表現は、セット内の比率を抑える。採用する場合は、シリーズ性やターゲットとの適合理由を明示する。行動に日常メッセージを組み合わせ、用途を広げる。

### 4. 主感情を大きく見せる

表情、手、四肢、姿勢など感情を表すパーツは、体の比率に埋もれない大きさにする。一つの画像に複数の感情や意図を詰め込まず、主メッセージを一つに絞る。

### 5. 文字で使いどころを明確にする

文字入りを基本とし、挨拶や返事などの用途がすぐ分かる短い文言にする。文字なしは、絵だけで感情と使いどころが明確な場合に限る。

### 6. 小さい画面で読める文字にする

文字数を必要最小限にし、太く大きく配置する。トーク背景に馴染まないよう、文字には明確なアウトラインまたは吹き出しを付ける。縮小表示で読めない場合は、文字を短くするか、絵の情報量を減らす。

## 制作前の判定表

| 判定 | 条件 |
|---|---|
| 必須 | 日常の返事・挨拶・感情補足のいずれかに使える |
| 必須 | 主感情が一つで、表情・動き・文字が同じ意味を示す |
| 必須 | 文字がある場合、短く太く大きく、アウトライン付き |
| 推奨 | ポジティブ表現がセットの中心を占める |
| 推奨 | 送る相手が限定されず、複数の日常場面で使える |
| 要検討 | 行動・趣味・ネガティブ表現だけで、用途が限定される |
