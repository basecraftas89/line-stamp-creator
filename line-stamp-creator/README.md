# Stamp Cut

複数枚の元画像にまとめられたイラストを、LINEスタンプ用の正方形PNGへ一括分割するローカルWebアプリです。

標準は2列×2行で、1枚につき4分割します。3枚を選べば12枚を生成します。列・行は必要に応じて変更できます。ZIP内のファイル名は `source_01_sticker_01.png` のように元画像番号と分割番号を含めます。

切り出し時は元画像全体から背景を必ず削除し、透過した要素の連結した塊を検出します。各塊の中心位置で4区画へ割り当てるため、区画をまたぐ塊も途中で切らず、隣の区画の要素を取り込みにくい方式です。保存するPNGとZIPは常に背景透過です。

## 起動

```bash
cd /Users/kantoshi/01_Sleeport/line-stamp-splitter
npm start
```

ブラウザで http://localhost:4173 を開きます。

画像はブラウザ内だけで処理され、外部へアップロードされません。初期設定は2列×2行です。
